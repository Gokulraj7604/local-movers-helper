# Local Movers Helper

Premium React + Vite + Tailwind CSS frontend for a moving-labor business.

## Included

- Responsive premium homepage
- Services listing and dynamic service details
- About page
- Pricing page
- Contact / booking request form
- Customer login and registration screens
- Blog listing with search and category filter
- Dynamic blog article pages
- 404 page
- Single responsive navigation/layout system
- Netlify SPA fallback (`public/_redirects`)
- Project-related moving images from Unsplash

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Important

This is a frontend project. Login, registration, booking persistence, owner/admin dashboard, payment and notifications still require a backend/database integration.

Replace the demo contact details in `src/data/siteData.js` before production.
